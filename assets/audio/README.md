# Audio — Radio Soy Tungurahua

La señal utiliza un motor de programación continua por bloques. Los audios se reproducen en serie y, al terminar el último, el ciclo vuelve al primero. El punto de entrada se sincroniza según la hora para que quien pulse reproducir se incorpore a la emisión en curso y no al inicio del archivo.

Los archivos grandes de programación no se guardan dentro del repositorio porque superan el límite práctico de carga web. Se publican como assets de GitHub Releases.

Release activo: `radio-v1`.

Bloques de programación:

1. `radio-soy-tungurahua.mp3` — primer bloque, asset del release `radio-v1`.
2. `radio-soy-tungurahua-2.mp3` — segundo bloque, debe adjuntarse al mismo release `radio-v1`.

La lista técnica se administra desde `assets/js/radio-live.js`.

No subir aquí música de terceros sin la autorización o licencia correspondiente.
